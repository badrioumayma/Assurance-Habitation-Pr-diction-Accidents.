# 📊 Insurance Claim Prediction - Machine Learning Project

This project aims to develop a **machine learning model** capable of predicting whether a building will have an insurance claim during the coverage period.

The work is based on a dataset containing various information about buildings, including type, size, location, and structural characteristics.

## 🚀 Project Pipeline

The project follows a standard data science workflow:

- 🔍 **Exploratory Data Analysis (EDA)**  
  Understanding data distribution, identifying patterns, and analyzing relationships between variables.

- 🧹 **Data Preprocessing**  
  Handling missing values, encoding categorical variables, and treating outliers.

- ⚖️ **Class Imbalance Handling**  
  Applying techniques such as **Upsampling** and **SMOTE** to balance the dataset.

- 🤖 **Model Training**  
  Training and comparing multiple models:
  - Logistic Regression  
  - Random Forest  
  - MLP (Neural Network)  
  - Stacking Ensemble  

- 📈 **Model Evaluation**  
  Evaluating model performance using metrics such as accuracy, precision, recall, and F1-score.

## 🏆 Results

The final **Stacking model** achieved an accuracy of approximately **92%**, demonstrating strong predictive performance and good generalization ability.
